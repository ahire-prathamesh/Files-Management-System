**📌 Files-Management-System**\
A web-based Flask application that allows users to upload, view, download, update, and delete files with a user-friendly interface.

**🎯 Purpose**:\
Enables users to manage files efficiently through a web interface, supporting multiple file types (images, PDFs, and others) with previews and download options, while storing data securely in SQL Server.

**🛠 Tech Stack**:\
**Python (Flask)**- Backend web application\
**SQL Server**- Database for storing file data and metadata\
**HTML, CSS, JavaScript**- Frontend interface\
**pyodbc**- Database connection driver\
**Bootstrap**- UI styling and icons\

**📊 Key Features**:
- Upload files of any type with proper storage in SQL Server.
- Preview images and PDFs directly in the browser.
- Download files with one click.
- User can Update file content.
- Flash messages for success, error, and info notifications.
- User-friendly interface with modals for file previews.
